# SouEdu

**SouEdu** é um projeto de páginas estáticas (GitHub Pages) com dicas sobre como utilizar **licenças de software** — durante o vínculo acadêmico ou temporárias — concedidas a alunos de instituições de ensino, especialmente de nível superior ou profissionalizante, além de outros descontos de estudante.

## Acesse o site

👉 [https://kelsoncm.github.io/SouEdu/](https://kelsoncm.github.io/SouEdu/)

## Conteúdo

- **Início** – Visão geral sobre licenças educacionais
- **Licenças Durante o Vínculo** – Dicas de uso para licenças válidas enquanto a matrícula estiver ativa (a maioria dos casos reais)
- **Licenças Temporárias** – Dicas de uso para licenças/créditos com prazo ou cota fixos, independente do vínculo
- **Descontos de Estudante** – Outros benefícios de estudante que não são licença de software (streaming, IA, etc.)
